# COMP4300 - [Computer Networks](https://umanitoba.ca/science/sites/science/files/2023-08/COMP-4300.pdf)
Tracking the learning outcomes for the hands-on experience offered by this class.
Languages/Applications used:
- C++
- WireShark
- Linux
- NS-3.49

## Projects

1. Basic HTTP Proxy (C++)
- Handled incoming HTTP GET requests by validating before forwarding to the target server.
- Handled the corresponding HTTP response message by modifying the response, replacing keywords with a specific pattern, then sending the response back to the client making the initial response.  
  
2. Go-Back-N Automatic Repeat Request protocol implemented over UDP (C++ and ns-3)
- Investigating the effects of DATA packet and ACK loss on the performance of the Go-Back-N protocol over UDP.
- Running and using ns-3 + wireShark to simulate (and evaluate) a network.
